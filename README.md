### phantom-kit · `Open Source`

Wi-Fi security auditing suite for ESP8266.

Evil portal, deauth attack, beacon flood, and web dashboard — running on a $3 microcontroller. Built to understand these attacks at the hardware level and have a personal platform for practicing offensive security.

`C++ · Arduino · ESP8266 · PlatformIO`

[github.com/chrisq-dev/phantom-kit](https://github.com/chrisq-dev/phantom-kit)

### 12 Burger — Management System · `Delivered · Private (client)`

Two interconnected systems for a restaurant chain: a dual-monitor desktop POS (cashier + kitchen views) with real-time order routing and no internet dependency, and a web platform for staff management, shift control, daily task tracking, legal documents, and a consolidated real-time stats dashboard.

`Node.js · Electron · React · SQLite · Docker`

### Lanza Tu Post · `Professional Internship · Private`

SaaS platform for AI-powered social media content generation and publishing.

Dynamic template engine with Jinja2 on FastAPI, full Meta Graph API integration for direct publishing to Facebook and Instagram, 64 documented endpoints, and 59 automated tests.

`Python · FastAPI · React 19 · MySQL · Redis · AWS S3 · Gemini AI · Docker`
